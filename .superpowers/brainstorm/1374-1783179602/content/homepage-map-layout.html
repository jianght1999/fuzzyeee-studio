🏰 像素冒险地图 — 主页布局概念

三种世界地图布局方式，你觉得哪种更适合你的笔记世界？

A

🌍 横版卷轴世界

像经典横版RPG一样，地图从左到右展开。每个笔记领域是一栋建筑，像素小人默认站在起始点（家/传送门）。视野可左右滚动，新增领域就扩展地图边界。

B

🏝️ 群岛/浮岛世界

每个笔记领域是一个独立的浮岛或小地图块，主视角是俯瞰的群岛上散布着不同主题的区域。岛之间有像素小路/桥连接。新增领域 = 新浮岛出现。

C

🏙️ 像素小镇

主页是一个俯视/等距视角的像素小镇。吉他 → 音乐厅/酒馆，合成器 → 发明工坊，读书笔记 → 图书馆/书店。角色可以走向不同建筑。新增领域 = 新建筑出现在小镇里。
